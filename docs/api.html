Makine-okur kaynaklar

Sunum modeli: Statik dosya sitesi (HTML/Markdown). Sunucu tarafı uygulama yok.

İçerik: Kamuya açık bilgilendirme sayfaları; resmî Hacettepe üniversite portalı değildir.

API / kimlik doğrulama: Belirteç veya oturum gerektiren bir HTTP API yoktur. OAuth ve OpenID Connect keşif uçları kullanılmaz.

MCP: Bu alan adı altında MCP sunucusu veya sunucu kartı ile duyurulan bir uç nokta yoktur.

Keşif

  • RFC 9727 API kataloğu (linkset JSON)
  • Ana içerik özeti (Markdown, text/markdown)
  • Agent skills dizini — yalnızca site özeti, gezinme ve içerik keşfi; çalıştırılabilir araç veya API yeteneği ima edilmez.
